# Personal Portfolio Website

## Oasis Infobyte SIP - Web Development Level 1 - Task 2

### Project Description

This project is a responsive personal portfolio website created as part of the Oasis Infobyte Web Development Internship. The website presents my profile, skills, projects, and contact information in a clean and user-friendly design.

### Features

- Responsive navigation bar
- Hero section with name and role
- About Me section
- Skills section
- Project showcase
- Contact section
- GitHub and LinkedIn links
- Smooth scrolling
- Responsive design for different screen sizes
- Hover effects and modern UI

### Technologies Used

- HTML5
- CSS3
