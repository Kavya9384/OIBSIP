# Brew & Bloom - Landing Page

## Oasis Infobyte SIP - Web Development Level 1 - Task 1

Brew & Bloom is a responsive coffee shop landing page created using HTML5 and CSS3.

The website presents a modern and welcoming coffee shop design with information about the café, popular menu items, contact details, and social media links.

## Features

- Responsive navigation bar
- Hero section with headline and call-to-action button
- About section
- Popular menu section
- Call-to-action section
- Contact information
- Social media links
- Responsive design for desktop, tablet, and mobile devices
- CSS Grid and Flexbox layout
- Smooth scrolling navigation
- Hover effects
- Clean and consistent colour scheme

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- Responsive Media Queries
